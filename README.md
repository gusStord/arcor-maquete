# Arcor — Um Natal feito em família

[Visitar a maquete 3D](https://gusstord.github.io/arcor-maquete/)

Proposta independente de experiência natalina para Arcor. Maquete de apresentação com 16 módulos, modelos Tencent Hunyuan, ambientação Blender e visita interativa Three.js. O projeto não constitui instalação aprovada ou projeto executivo.

Este repositório contém somente a entrega web. A documentação de desenvolvimento e o arquivo Blender editável são mantidos separadamente.

Marca Arcor: imagem obtida no [site oficial](https://www.arcor.com/es/dist/images/logos/logo-arcor-2022.png). Three.js: licença MIT em `viewer/vendor/LICENSE`. A identificação de marcas não implica afiliação ou endosso.
